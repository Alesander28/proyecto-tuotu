# Partes comunes a todos los módulos

| Archivo | Qué hace |
|---|---|
| `api.js` | Cliente de la API (agrega el token; vuelve al inicio de sesión si la sesión ya no vale) |
| `formato.js` | Formato de dinero (S/ 22.00) |
| `Panel.jsx` | Menú lateral y barra superior; muestra solo las opciones permitidas al rol |
| `Inicio.jsx` | Pantalla de bienvenida |
| `estilos.css` | Estilos generales |
